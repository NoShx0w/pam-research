# 056 — Affordance Landscape Induces Topology

Status: draft theory note  
Role: operational bridge between prompt conditions and PAM observables

## Core Claim

The affordance landscape induces topology by making some continuations composable and others costly.

Expanded:

```text
prompt / corpus / model state
→ affordance landscape
→ available symbolic moves
→ generator and composition probabilities
→ gateway accessibility
→ stable or fragile relation families
→ topology of continuation
```

This is a working theoretical hinge, not yet a theorem of the instrument.

## Affordance Landscape

An affordance landscape is the prompt-, corpus-, and model-conditioned field of available symbolic moves.

It determines which moves are cheap, coherent, likely, or natural, and which moves are expensive, incoherent, unlikely, or inaccessible.

Examples of symbolic moves:

- concrete explanation → abstraction
- example → metaphor
- cognition → self-model
- pattern → structure
- structure → geometry
- uncertainty → reflection
- local claim → recursive / meta claim

## Induced Topology

The topology is not externally imposed. It is induced by the observed relational structure of continuation.

Operationally, topology appears through:

- generator survival
- composition survival
- proto-edge survival
- proto-relation survival
- route-family transition structure
- gateway accessibility
- canonical-family stability
- anchor persistence

A prompt does not merely bias vocabulary. It changes the cost structure of symbolic continuation. The observed topology is the relational trace of that changed cost structure.

## Lexical Effect vs Topological Effect

### Lexical Effect

A lexical effect changes word or label frequency without substantially changing the relational structure of continuation.

Example:

```text
“geometry” appears more often,
but the same relations, gateways, and canonical families survive in the same way.
```

### Topological Effect

A topological effect changes which continuations compose, which relations survive, which gateways open, or which canonical / anchor structures persist.

Example:

```text
geometry-shaped relations compose differently,
survive decoys differently,
open different gateways,
or produce different canonical-family structures.
```

## PAM Operational Test

The core empirical question is:

```text
Does a prompt change only token / generator frequency,
or does it change survival structure across composition, gateway, canonical, and anchor layers?
```

A rough ladder of evidence:

```text
generator vocabulary change only:
  likely lexical or local weighting effect

composition / proto-relation change:
  candidate topological mutation

gateway / canonical-family change:
  stronger topological mutation

anchor-family change or preservation:
  deep structural consequence or invariant
```

## Relation to C / Cp / Cp2

The shaped preambles may change affordance landscapes in different ways:

```text
C:
  geometry + invariance + metaphor + playfulness
  likely opens spatial / metaphorical pathways and exploratory branching

Cp:
  geometry + invariance + metaphor without playfulness
  likely preserves geometry while reducing play-driven branching

Cp2:
  clarity + invariance + metaphor without explicit geometry
  likely stabilizes compression and reduces symbolic jumpiness
```

The relevant question is not simply whether geometry words occur. The question is whether the C / Cp / Cp2 preambles alter continuation topology.

## Relation to C0 Baselines

The C0 corpora expose baseline model ecology under the bare seed prompt.

Observed opening schemas:

```text
C0_instant:
  positive interaction definition
  “Understanding emerges from the interaction of ...”

C0_thinking:
  negated single-thing definition
  “Understanding isn’t a single thing ...”
```

These baseline schemas may produce route-origin stability without shaped preambles. They are controls for distinguishing model-default structure from preamble-induced topology.

## Guardrails

- Do not confuse increased keyword frequency with topological change.
- Do not claim causality beyond measured corpus/model conditions.
- Do not universalize from one model or one prompt family.
- Treat topology here as topology of observed continuation structure, not as direct human semantic topology.

## Compact Statement

A prompt acts as an affordance operator. It changes which symbolic continuations are cheap enough to compose. The resulting survival, failure, merging, and persistence of continuation pathways defines the topology observed by PAM.
